standing-bot

A bot that stays. One folder, one thread, scheduled check-ins.

standing-bot is a skill for T3 Code. It turns one thread into an assistant that keeps its memory in files, wakes on a schedule, and hands the work to workers.

How it works

Scheduled check-inswake the bot
Youtalk in the bot's thread
The botone long-lived thread, the front desk
Workersone fresh thread for each task
The folderits memory: the bot file, NOW.md, log, notes, procedures
  • The folder is the memoryEach bot has one folder. NOW.md holds the current view. The log and the notes keep the rest. The chat can be reset at any time.
  • The thread is the botOne long-lived T3 Code thread talks to you and keeps track. It is a front desk. It does not do the work.
  • Check-ins wake itScheduled tasks start a run: a heartbeat, and daily, weekly or monthly check-ins. You choose which ones are on.
  • Workers do the workEvery check and every task goes to a fresh worker thread. The worker reports back in at most 20 lines.
  • You stay in chargeA bot changes its goal, rules or check-ins only on your word. It asks before it writes outward or does anything that cannot be undone.
  • A chief can watch the restOne optional bot sees all the others and tells you what waits on you.

A check-in, step by step

  1. A scheduled task sends the bot its check-in.
  2. The bot reads NOW.md and its check-in table. Outside its hours it answers off hours and stops.
  3. It hands the check to one worker, with the procedure to follow.
  4. The worker reports. Line 1 says what you must do, or "nothing needed".
  5. The bot updates NOW.md and the log.
  6. It speaks to you only if line 1 asks something of you. Otherwise it says quiet.

Start

Install the skill in Claude Code:

claude plugin marketplace add wannaFlyKa/standing-bot
claude plugin install standing-bot@standing-bot

Then open a thread in T3 Code and say new bot. The skill asks a few questions and sets the bot up.

The Codex install and the full guide are in the README.

Where it stands

  • Tested with Claude Code as the agent, inside T3 Code. Other agents are not tested yet.
  • The tests ran on a private build of T3 Code. The public build was checked by reading its source, not by running it.
  • T3 Code is the only host for now. Other hosts may come later, for example the Claude Code desktop app on its own.
  • The rules are two Markdown files. Nothing enforces them. The README lists the known gaps.
