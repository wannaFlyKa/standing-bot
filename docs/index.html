01 / How it works

A front desk, not a worker

The bot talks to you, keeps track and remembers. The work itself goes to workers, each in a fresh thread.

The folderits memory: the bot file, NOW.md, log, notes, procedures
  • 01The folder is the memory

    Each bot has one folder. NOW.md holds the current view. The log and the notes keep the rest.

  • 02The thread is the bot

    One long-lived T3 Code thread talks to you and keeps track. Its chat can be reset at any time.

  • 03Check-ins wake it

    Scheduled tasks start a run. You choose which check-ins are on, and in which hours they may run.

  • 04Workers do the work

    Every check and every task goes to a fresh worker thread. The worker reports back in at most 20 lines.

  • 05You stay in charge

    A bot changes its goal, rules or check-ins only on your word. It asks before it writes outward or does anything that cannot be undone.

  • 06A chief can watch the rest

    One optional bot sees all the others and tells you what waits on you.

02 / A check-in

Step by step

A check-in is a scheduled task that wakes the bot. Most of them end with one word.

  1. A scheduled task sends the bot its check-in.
  2. The bot reads NOW.md and its check-in table. Outside its hours it answers off hours and stops.
  3. It hands the check to one worker, with the procedure to follow.
  4. The worker reports. Line 1 says what you must do, or "nothing needed".
  5. The bot updates NOW.md and the log.
  6. It speaks to you only if line 1 asks something of you. Otherwise it says quiet.
03 / On disk

The chat is not the memory

What matters goes into a file in the same turn. The bots root is a local git repository, so every change has a history and an undo.

04 / Start

Five minutes to a first bot

You need T3 Code with a coding agent set up in it. Claude Code is the one that was tested.

$ claude plugin marketplace add wannaFlyKa/standing-bot
$ claude plugin install standing-bot@standing-bot
ThenSay new bot

Open a thread in T3 Code with full access and say it. Give the bot a name and one line on its purpose.

AndAnswer its questions

The bot asks for its goal, key results, check-ins and limits, one question at a time. Then it tells you when the next check-in runs.

The Codex install and the full guide are in the README.

05 / Status

Where it stands

This is an early release. Here is what was tested and what was not.

  • TestedWith Claude Code as the agent, inside T3 Code 0.1.9. Install from GitHub works for Claude Code and Codex.
  • Not yetOther agents. A bot that runs on Codex is not tested.
  • Not yetOther versions of T3 Code. The tests ran on T3 Code 0.1.9.
  • For nowT3 Code is the only host. Other hosts may come later, for example the Claude Code desktop app on its own.
  • Know thisThe rules are two Markdown files. With Claude Code, a guard blocks every MCP tool in the bot thread except the T3 Code tools the bot needs. Nothing enforces the rest. The README lists the known gaps.
